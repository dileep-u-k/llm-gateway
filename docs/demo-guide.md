# Demo Guide

## End-user demo

1. Open `/`.
2. Upload a document and an image.
3. Ask for a grounded comparison.
4. Show route metadata, governance metadata, and artifact lineage.
5. Switch to an async workflow such as `video_generation_hook`.

## Admin demo

1. Open `/admin`.
2. Show provider/model registry, recent jobs, and audit events.
3. Run a policy simulation for the `ops` workspace.
4. Apply a workspace override and re-run the simulation.
5. Replay an orchestration or inspect the recent traces snapshot.
